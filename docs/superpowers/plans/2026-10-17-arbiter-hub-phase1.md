# Arbiter Hub Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a federation hub for workload attestation that federates Keylime, Trustee, cosign, and Rekor backends behind a unified REST API, manages workload lifecycle via a 7-state machine, releases secrets through KBS, and exposes read-only MCP tools for agentic workflows.

**Architecture:** FastAPI REST API orchestrates four attestation backends through a common adapter Protocol. PostgreSQL stores workload state, attestation records, policies, audit log, and KBS secrets. A separate MCP server exposes read-only tools that proxy to the API. A Clevis pin integrates with RHEL-native NBDE. All containers orchestrated by Quadlet on RHEL, built on RHHI (or UBI10-minimal fallback) base images.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2.0 (async + asyncpg), Pydantic v2, Alembic, pytest + pytest-asyncio + httpx, FastMCP, opentelemetry-sdk, PyYAML, cryptography (Fernet for KBS secret encryption)

**Spec:** `docs/superpowers/specs/2026-10-17-arbiter-hub-design.md`

## Global Constraints

- Python >= 3.12 required (match UBI10/RHHI runtime)
- All async: FastAPI + async SQLAlchemy + asyncpg. No sync DB calls.
- Pydantic v2 models for all API schemas. SQLAlchemy 2.0 style (mapped_column).
- No mocked databases in tests — use a real test PostgreSQL (per project practice).
- Secrets never in environment variables — use config files or podman secret at deploy time.
- OpenAPI 3.1 auto-generated by FastAPI. RFC 7807 Problem Details for errors.
- SCIM-style pagination on list endpoints (`?startIndex=1&count=25`).
- All state transitions logged to audit_log table.
- Container images target RHHI base; UBI10-minimal as fallback.
- No `Privileged=true` in any Quadlet file.

## Review Focus

1. **Concurrent state transitions**: Two simultaneous `/attest` calls for the same workload could race. Expect: only one transition succeeds; the other gets a 409 Conflict. Test with `SELECT ... FOR UPDATE` row locking.
2. **KBS secret release after revocation**: A workload is revoked between the policy check and the secret decrypt. Expect: no secret released. Test that the gate re-checks state inside the same transaction.
3. **Stale TTL edge case**: Workload goes Healthy with `stale_ttl_seconds=0`. Expect: immediately transitions to Stale on next scheduler tick, not stuck in Healthy forever.
4. **MCP scope bypass**: Agent A queries workload owned by Agent B via `check_workload_status`. Expect: 404 (not 403, to avoid leaking existence). Test scope filter on every MCP tool.
5. **Backend unavailable during attestation**: Keylime verifier is unreachable. Expect: `AttestationVerdict.UNAVAILABLE` returned, workload stays in current state (not moved to Failed). Test that UNAVAILABLE != FAIL.

```python
import enum
import uuid
from datetime import datetime, timezone
from sqlalchemy import (
    String, Integer, Boolean, Text, DateTime, ForeignKey, Index, Enum as SAEnum,
    LargeBinary, UniqueConstraint,
)
from sqlalchemy.dialects.postgresql import UUID, JSONB
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, relationship
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker, AsyncSession
from typing import AsyncGenerator
from server.config import settings


class WorkloadType(str, enum.Enum):
    AGENTIC = "agentic"
    CVM = "cvm"
    SERVICE = "service"


class WorkloadState(str, enum.Enum):
    REGISTERED = "registered"
    ATTESTING = "attesting"
    HEALTHY = "healthy"
    STALE = "stale"
    FAILED = "failed"
    UNDER_REMEDIATION = "under_remediation"
    REVOKED = "revoked"


class AttestationVerdict(str, enum.Enum):
    PASS = "pass"
    FAIL = "fail"
    ERROR = "error"
    UNAVAILABLE = "unavailable"


class BackendType(str, enum.Enum):
    KEYLIME = "keylime"
    TRUSTEE = "trustee"
    COSIGN = "cosign"
    REKOR = "rekor"


class Base(DeclarativeBase):
    pass


class Workload(Base):
    __tablename__ = "workloads"

    id: Mapped[uuid.UUID] = mapped_column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    ipa_principal: Mapped[str] = mapped_column(String(255), unique=True, nullable=False)
    display_name: Mapped[str] = mapped_column(String(255), nullable=False)
    workload_type: Mapped[WorkloadType] = mapped_column(SAEnum(WorkloadType), nullable=False)
    current_state: Mapped[WorkloadState] = mapped_column(
        SAEnum(WorkloadState), nullable=False, default=WorkloadState.REGISTERED
    )
    backend_type: Mapped[BackendType] = mapped_column(SAEnum(BackendType), nullable=False)
    stale_ttl_seconds: Mapped[int] = mapped_column(Integer, nullable=False, default=3600)
    registered_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, default=lambda: datetime.now(timezone.utc)
    )
    last_attested_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    metadata_: Mapped[dict] = mapped_column("metadata", JSONB, default=dict)

    attestation_records: Mapped[list["AttestationRecord"]] = relationship(back_populates="workload")
    state_transitions: Mapped[list["StateTransition"]] = relationship(back_populates="workload")


class AttestationRecord(Base):
    __tablename__ = "attestation_records"

    id: Mapped[uuid.UUID] = mapped_column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    workload_id: Mapped[uuid.UUID] = mapped_column(ForeignKey("workloads.id"), nullable=False)
    backend: Mapped[BackendType] = mapped_column(SAEnum(BackendType), nullable=False)
    verdict: Mapped[AttestationVerdict] = mapped_column(SAEnum(AttestationVerdict), nullable=False)
    evidence_hash: Mapped[str | None] = mapped_column(String(128))
    policy_hash: Mapped[str | None] = mapped_column(String(128))
    detail: Mapped[dict] = mapped_column(JSONB, default=dict)
    rekor_entry_uuid: Mapped[str | None] = mapped_column(String(255))
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, default=lambda: datetime.now(timezone.utc)
    )

    workload: Mapped["Workload"] = relationship(back_populates="attestation_records")

    __table_args__ = (
        Index("idx_attest_workload", "workload_id", created_at.desc()),
    )


class StateTransition(Base):
    __tablename__ = "state_transitions"

    id: Mapped[uuid.UUID] = mapped_column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    workload_id: Mapped[uuid.UUID] = mapped_column(ForeignKey("workloads.id"), nullable=False)
    from_state: Mapped[WorkloadState] = mapped_column(SAEnum(WorkloadState), nullable=False)
    to_state: Mapped[WorkloadState] = mapped_column(SAEnum(WorkloadState), nullable=False)
    triggered_by: Mapped[str] = mapped_column(String(255), nullable=False)
    justification: Mapped[str | None] = mapped_column(Text)
    rekor_entry_uuid: Mapped[str | None] = mapped_column(String(255))
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, default=lambda: datetime.now(timezone.utc)
    )

    workload: Mapped["Workload"] = relationship(back_populates="state_transitions")

    __table_args__ = (
        Index("idx_transitions_workload", "workload_id", created_at.desc()),
    )


class Policy(Base):
    __tablename__ = "policies"

    id: Mapped[uuid.UUID] = mapped_column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    name: Mapped[str] = mapped_column(String(255), unique=True, nullable=False)
    policy_type: Mapped[str] = mapped_column(String(50), nullable=False, default="simple")
    policy_content: Mapped[dict] = mapped_column(JSONB, nullable=False)
    scope: Mapped[str | None] = mapped_column(String(255))
    active: Mapped[bool] = mapped_column(Boolean, nullable=False, default=True)
    created_by: Mapped[str] = mapped_column(String(255), nullable=False)
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, default=lambda: datetime.now(timezone.utc)
    )
    updated_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, default=lambda: datetime.now(timezone.utc)
    )


class AuditLog(Base):
    __tablename__ = "audit_log"

    id: Mapped[uuid.UUID] = mapped_column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    actor: Mapped[str] = mapped_column(String(255), nullable=False)
    actor_type: Mapped[str] = mapped_column(String(50), nullable=False)
    action: Mapped[str] = mapped_column(String(100), nullable=False)
    target_type: Mapped[str | None] = mapped_column(String(50))
    target_id: Mapped[uuid.UUID | None] = mapped_column(UUID(as_uuid=True))
    detail: Mapped[dict] = mapped_column(JSONB, default=dict)
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, default=lambda: datetime.now(timezone.utc)
    )

    __table_args__ = (
        Index("idx_audit_created", created_at.desc()),
        Index("idx_audit_actor", "actor"),
    )


class KBSSecret(Base):
    __tablename__ = "kbs_secrets"

    id: Mapped[uuid.UUID] = mapped_column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    repo: Mapped[str] = mapped_column(String(255), nullable=False)
    secret_type: Mapped[str] = mapped_column(String(255), nullable=False)
    tag: Mapped[str] = mapped_column(String(255), nullable=False)
    encrypted_value: Mapped[bytes] = mapped_column(LargeBinary, nullable=False)
    required_state: Mapped[WorkloadState] = mapped_column(
        SAEnum(WorkloadState), nullable=False, default=WorkloadState.HEALTHY
    )
    workload_scope: Mapped[str | None] = mapped_column(String(255))
    created_by: Mapped[str] = mapped_column(String(255), nullable=False)
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, default=lambda: datetime.now(timezone.utc)
    )
    rotated_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True))

    __table_args__ = (
        UniqueConstraint("repo", "secret_type", "tag"),
    )


engine = create_async_engine(settings.database_url)
async_session = async_sessionmaker(engine, expire_on_commit=False)


async def get_session() -> AsyncGenerator[AsyncSession, None]:
    async with async_session() as session:
        yield session
```

```python
# server/state/machine.py
import uuid
from datetime import datetime, timezone
from sqlalchemy import select, update
from sqlalchemy.ext.asyncio import AsyncSession
from server.models.db import Workload, StateTransition, WorkloadState, AuditLog


class InvalidTransitionError(Exception):
    def __init__(self, from_state: WorkloadState, to_state: WorkloadState, reason: str):
        self.from_state = from_state
        self.to_state = to_state
        self.reason = reason
        super().__init__(f"{from_state.value} -> {to_state.value}: {reason}")


VALID_TRANSITIONS: dict[WorkloadState, set[WorkloadState]] = {
    WorkloadState.REGISTERED: {WorkloadState.ATTESTING},
    WorkloadState.ATTESTING: {WorkloadState.HEALTHY, WorkloadState.FAILED},
    WorkloadState.HEALTHY: {WorkloadState.STALE, WorkloadState.REVOKED},
    WorkloadState.STALE: {WorkloadState.ATTESTING},
    WorkloadState.FAILED: {WorkloadState.UNDER_REMEDIATION, WorkloadState.REVOKED},
    WorkloadState.UNDER_REMEDIATION: {WorkloadState.ATTESTING},
    WorkloadState.REVOKED: set(),
}


def validate_transition(from_state: WorkloadState, to_state: WorkloadState) -> None:
    allowed = VALID_TRANSITIONS.get(from_state, set())
    if to_state not in allowed:
        if from_state == WorkloadState.REVOKED:
            reason = "revoked is terminal — requires new enrollment"
        elif from_state == WorkloadState.FAILED and to_state == WorkloadState.HEALTHY:
            reason = "prohibited — must go through Under Remediation -> Attesting -> Healthy"
        else:
            reason = f"not a valid transition from {from_state.value}"
        raise InvalidTransitionError(from_state, to_state, reason)


async def transition(
    session: AsyncSession,
    workload: Workload,
    to_state: WorkloadState,
    triggered_by: str,
    justification: str | None = None,
) -> StateTransition:
    validate_transition(workload.current_state, to_state)

    from_state = workload.current_state
    workload.current_state = to_state

    record = StateTransition(
        workload_id=workload.id,
        from_state=from_state,
        to_state=to_state,
        triggered_by=triggered_by,
        justification=justification,
    )
    session.add(record)

    audit = AuditLog(
        actor=triggered_by,
        actor_type="system",
        action="state_transition",
        target_type="workload",
        target_id=workload.id,
        detail={"from": from_state.value, "to": to_state.value, "justification": justification},
    )
    session.add(audit)

    return record


async def check_stale_workloads(session: AsyncSession) -> list[uuid.UUID]:
    now = datetime.now(timezone.utc)
    stmt = select(Workload).where(
        Workload.current_state == WorkloadState.HEALTHY,
        Workload.last_attested_at.isnot(None),
    )
    result = await session.execute(stmt)
    stale_ids = []
    for workload in result.scalars():
        elapsed = (now - workload.last_attested_at).total_seconds()
        if elapsed >= workload.stale_ttl_seconds:
            await transition(session, workload, WorkloadState.STALE, "staleness_scheduler")
            stale_ids.append(workload.id)
    await session.commit()
    return stale_ids
```

```python
import asyncio
import logging
from server.models.db import async_session
from server.state.machine import check_stale_workloads

log = logging.getLogger(__name__)


class StalenessScheduler:
    def __init__(self, interval_seconds: int = 60):
        self.interval = interval_seconds
        self._task: asyncio.Task | None = None

    async def _run(self):
        while True:
            try:
                async with async_session() as session:
                    stale_ids = await check_stale_workloads(session)
                    if stale_ids:
                        log.info("Transitioned %d workloads to Stale", len(stale_ids))
            except Exception:
                log.exception("Staleness check failed")
            await asyncio.sleep(self.interval)

    def start(self):
        self._task = asyncio.create_task(self._run())

    async def stop(self):
        if self._task:
            self._task.cancel()
            try:
                await self._task
            except asyncio.CancelledError:
                pass
```

```python
# server/policy/engine.py
from dataclasses import dataclass, field
from typing import Protocol, runtime_checkable


@dataclass
class PolicyDecision:
    allowed: bool
    obligations: list[str] = field(default_factory=list)
    reason: str = ""


@runtime_checkable
class PolicyEngine(Protocol):
    async def evaluate(
        self, subject: str, action: str, resource: str, context: dict
    ) -> PolicyDecision: ...


class SimpleRulesEngine:
    def __init__(self, policies: list[dict]):
        self._policies = policies

    async def evaluate(
        self, subject: str, action: str, resource: str, context: dict
    ) -> PolicyDecision:
        for policy in self._policies:
            for rule in policy.get("rules", []):
                if rule.get("action") != action:
                    continue
                requirements = rule.get("require", {})
                if self._check_requirements(requirements, context):
                    return PolicyDecision(
                        allowed=True,
                        obligations=policy.get("obligations", []),
                        reason=f"matched policy '{policy['name']}'",
                    )
                else:
                    return PolicyDecision(
                        allowed=False,
                        reason=f"policy '{policy['name']}' requirements not met",
                    )
        return PolicyDecision(allowed=False, reason="no matching policy for action")

    def _check_requirements(self, requirements: dict, context: dict) -> bool:
        for key, expected in requirements.items():
            actual = context.get(key)
            if key == "attestation_age_max":
                age = context.get("attestation_age", float("inf"))
                if age > expected:
                    return False
            elif isinstance(expected, list):
                if actual not in expected:
                    return False
            elif isinstance(expected, bool):
                if actual != expected:
                    return False
            else:
                if actual != expected:
                    return False
        return True
```

```python
from dataclasses import dataclass, field
from datetime import datetime
from typing import Protocol, runtime_checkable
from server.models.db import AttestationVerdict, Workload


@dataclass
class AttestationResult:
    verdict: AttestationVerdict
    backend: str
    evidence_hash: str
    detail: dict = field(default_factory=dict)
    timestamp: datetime = field(default_factory=lambda: datetime.now(__import__("datetime").timezone.utc))


@dataclass
class EnrollResult:
    success: bool
    backend: str
    detail: dict = field(default_factory=dict)


@dataclass
class RevokeResult:
    success: bool
    backend: str
    detail: dict = field(default_factory=dict)


@dataclass
class BackendHealth:
    healthy: bool
    backend: str
    last_check: datetime
    detail: str = ""


@runtime_checkable
class AttestationBackend(Protocol):
    async def verify(self, workload: Workload) -> AttestationResult: ...
    async def enroll(self, workload: Workload, policy: dict) -> EnrollResult: ...
    async def revoke(self, workload: Workload) -> RevokeResult: ...
    async def health(self) -> BackendHealth: ...


class BackendRegistry:
    def __init__(self):
        self._backends: dict[str, AttestationBackend] = {}

    def register(self, name: str, backend: AttestationBackend) -> None:
        self._backends[name] = backend

    def get(self, name: str) -> AttestationBackend:
        return self._backends[name]

    async def health_all(self) -> dict[str, BackendHealth]:
        results = {}
        for name, backend in self._backends.items():
            results[name] = await backend.health()
        return results

    def all_names(self) -> list[str]:
        return list(self._backends.keys())
```

```python
# server/backends/keylime.py
import hashlib
import logging
from datetime import datetime, timezone
import httpx
from server.backends.base import (
    AttestationBackend, AttestationResult, EnrollResult, RevokeResult, BackendHealth,
)
from server.models.db import AttestationVerdict, Workload

log = logging.getLogger(__name__)


class KeylimeBackend:
    def __init__(
        self,
        verifier_url: str,
        ca_cert: str,
        client_cert: str,
        client_key: str,
        timeout: float = 10.0,
    ):
        self._verifier_url = verifier_url.rstrip("/")
        self._ca_cert = ca_cert
        self._client_cert = client_cert
        self._client_key = client_key
        self._timeout = timeout

    def _build_client(self) -> httpx.AsyncClient:
        kwargs: dict = {"timeout": self._timeout, "verify": False}
        if self._ca_cert and self._client_cert and self._client_key:
            kwargs["verify"] = self._ca_cert
            kwargs["cert"] = (self._client_cert, self._client_key)
        return httpx.AsyncClient(**kwargs)

    async def verify(self, workload: Workload) -> AttestationResult:
        agent_id = workload.metadata_.get("keylime_agent_uuid", "")
        if not agent_id:
            return AttestationResult(
                verdict=AttestationVerdict.ERROR,
                backend="keylime",
                evidence_hash="",
                detail={"error": "no keylime_agent_uuid in workload metadata"},
            )
        try:
            async with self._build_client() as client:
                resp = await client.get(f"{self._verifier_url}/v2.1/agents/{agent_id}")
                resp.raise_for_status()
                data = resp.json()
                results = data.get("results", {})
                op_state = results.get("operational_state", -1)
                # Keylime op_state: 7 = GET_QUOTE (attesting), others vary
                # A healthy agent has op_state that indicates verified
                ima_hash = hashlib.sha256(str(results).encode()).hexdigest()
                if op_state in (7, 8, 9):  # verified states
                    verdict = AttestationVerdict.PASS
                else:
                    verdict = AttestationVerdict.FAIL
                return AttestationResult(
                    verdict=verdict,
                    backend="keylime",
                    evidence_hash=ima_hash,
                    detail={"operational_state": op_state, "agent_id": agent_id},
                )
        except httpx.HTTPError as e:
            log.warning("Keylime verify failed for %s: %s", agent_id, e)
            return AttestationResult(
                verdict=AttestationVerdict.UNAVAILABLE,
                backend="keylime",
                evidence_hash="",
                detail={"error": str(e)},
            )

    async def enroll(self, workload: Workload, policy: dict) -> EnrollResult:
        agent_id = workload.metadata_.get("keylime_agent_uuid", "")
        agent_ip = workload.metadata_.get("keylime_agent_ip", "")
        if not agent_id or not agent_ip:
            return EnrollResult(
                success=False,
                backend="keylime",
                detail={"error": "keylime_agent_uuid and keylime_agent_ip required in metadata"},
            )
        try:
            async with self._build_client() as client:
                payload = {
                    "v": "2.1",
                    "agent_id": agent_id,
                    "ip": agent_ip,
                    "tpm_policy": policy.get("tpm_policy", "{}"),
                    "runtime_policy": policy.get("runtime_policy", ""),
                }
                resp = await client.post(f"{self._verifier_url}/v2.1/agents/{agent_id}", json=payload)
                resp.raise_for_status()
                return EnrollResult(success=True, backend="keylime", detail=resp.json())
        except httpx.HTTPError as e:
            return EnrollResult(success=False, backend="keylime", detail={"error": str(e)})

    async def revoke(self, workload: Workload) -> RevokeResult:
        agent_id = workload.metadata_.get("keylime_agent_uuid", "")
        if not agent_id:
            return RevokeResult(success=False, backend="keylime", detail={"error": "no agent_id"})
        try:
            async with self._build_client() as client:
                resp = await client.delete(f"{self._verifier_url}/v2.1/agents/{agent_id}")
                resp.raise_for_status()
                return RevokeResult(success=True, backend="keylime", detail=resp.json())
        except httpx.HTTPError as e:
            return RevokeResult(success=False, backend="keylime", detail={"error": str(e)})

    async def health(self) -> BackendHealth:
        try:
            async with self._build_client() as client:
                resp = await client.get(f"{self._verifier_url}/v2.1/agents/")
                resp.raise_for_status()
                return BackendHealth(
                    healthy=True,
                    backend="keylime",
                    last_check=datetime.now(timezone.utc),
                    detail=f"verifier reachable, {len(resp.json().get('results', {}).get('uuids', []))} agents",
                )
        except Exception as e:
            return BackendHealth(
                healthy=False,
                backend="keylime",
                last_check=datetime.now(timezone.utc),
                detail=str(e),
            )
```

```python
                import hashlib
                eh = hashlib.sha256(evidence.encode()).hexdigest()
                if data.get("attestation_pass", False):
                    return AttestationResult(
                        verdict=AttestationVerdict.PASS,

                        detail=data,

                        detail=data,
                    )

                evidence_hash="",
                detail={"error": str(e)},
```

```python
import asyncio
import hashlib
import logging
import tempfile

class CosignBackend:
    def __init__(self, cosign_binary: str = "cosign", rekor_url: str = ""):
        self._binary = cosign_binary
        self._rekor_url = rekor_url

    async def verify(self, workload: Workload) -> AttestationResult:
        artifact_ref = workload.metadata_.get("artifact_ref", "")
        if not artifact_ref:
            return AttestationResult(
                verdict=AttestationVerdict.ERROR,
                backend="cosign",
                evidence_hash="",
                detail={"error": "no artifact_ref in workload metadata"},
            )
        try:
            cmd = [self._binary, "verify", "--yes", artifact_ref]
            if self._rekor_url:
                cmd.extend(["--rekor-url", self._rekor_url])
            proc = await asyncio.create_subprocess_exec(
                *cmd,
                stdout=asyncio.subprocess.PIPE,
                stderr=asyncio.subprocess.PIPE,
            )
            stdout, stderr = await asyncio.wait_for(proc.communicate(), timeout=30)
            evidence_hash = hashlib.sha256(stdout).hexdigest()
            if proc.returncode == 0:
                return AttestationResult(
                    verdict=AttestationVerdict.PASS,
                    backend="cosign",
                    evidence_hash=evidence_hash,
                    detail={"output": stdout.decode()[:500]},
                )
            else:
                return AttestationResult(
                    verdict=AttestationVerdict.FAIL,
                    backend="cosign",
                    evidence_hash=evidence_hash,
                    detail={"error": stderr.decode()[:500]},
                )
        except asyncio.TimeoutError:
            return AttestationResult(
                verdict=AttestationVerdict.ERROR,
                backend="cosign",
                evidence_hash="",
                detail={"error": "cosign verify timed out"},
            )
        except FileNotFoundError:
            return AttestationResult(
                verdict=AttestationVerdict.UNAVAILABLE,
                backend="cosign",
                evidence_hash="",
                detail={"error": f"cosign binary not found: {self._binary}"},
            )

    async def enroll(self, workload: Workload, policy: dict) -> EnrollResult:
        return EnrollResult(success=True, backend="cosign", detail={"note": "cosign has no enrollment — verify on demand"})

    async def revoke(self, workload: Workload) -> RevokeResult:
        return RevokeResult(success=True, backend="cosign", detail={"note": "cosign has no revocation — signatures are permanent"})

    async def health(self) -> BackendHealth:
        try:
            proc = await asyncio.create_subprocess_exec(
                self._binary, "version",
                stdout=asyncio.subprocess.PIPE,
                stderr=asyncio.subprocess.PIPE,
            )
            stdout, _ = await asyncio.wait_for(proc.communicate(), timeout=5)

                healthy=proc.returncode == 0,
                backend="cosign",

            )
```

```python
# server/auth/dependencies.py
from fastapi import Request, HTTPException, Depends
from server.auth.models import CallerIdentity
from server.auth.rbac import check_permission


async def get_caller(request: Request) -> CallerIdentity:
    # Phase 1: extract from X-Caller-* headers (dev mode)
    # Production: OIDC token validation or client cert extraction
    principal = request.headers.get("X-Caller-Principal", "anonymous")
    actor_type = request.headers.get("X-Caller-Type", "admin")
    roles = request.headers.get("X-Caller-Roles", "attestation-admin").split(",")
    scopes = request.headers.get("X-Caller-Scopes", "*").split(",")
    return CallerIdentity(
        principal=principal,
        actor_type=actor_type,
        roles=[r.strip() for r in roles],
        scopes=[s.strip() for s in scopes],
    )


def require_permission(action: str):
    async def _check(caller: CallerIdentity = Depends(get_caller)):
        if not check_permission(caller, action):
            raise HTTPException(
                status_code=403,
                detail={"type": "about:blank", "title": "Forbidden", "status": 403,
                        "detail": f"permission denied for action: {action}"},
            )
        return caller
    return Depends(_check)
```

```python
    workload_type: WorkloadType | None = None,
    start_index: int = Query(1, ge=1),
    count: int = Query(25, ge=1, le=100),
    session: AsyncSession = Depends(get_session),
    caller: CallerIdentity = Depends(require_permission("read_workload")),

            if "@" in caller.principal else caller.scopes

    total = (await session.execute(count_stmt)).scalar_one()
    stmt = stmt.offset(start_index - 1).limit(count)
    result = await session.execute(stmt)
    items = [WorkloadRead.model_validate(w) for w in result.scalars()]
```

```python
from uuid import UUID
from fastapi import APIRouter, Depends, HTTPException

from server.models.db import Workload, AttestationRecord, WorkloadState, get_session

from server.auth.dependencies import require_permission
from server.auth.models import CallerIdentity

router = APIRouter()


@router.post("/workloads/{workload_id}/attest")
async def trigger_attestation(
    workload_id: UUID,
    session: AsyncSession = Depends(get_session),
    caller: CallerIdentity = Depends(require_permission("trigger_attestation")),
):
    stmt = select(Workload).where(Workload.id == workload_id).with_for_update()
    result = await session.execute(stmt)
    workload = result.scalar_one_or_none()
    if not workload:
        raise HTTPException(status_code=404, detail="workload not found")

    # Transition to Attesting if needed
    if workload.current_state in (WorkloadState.REGISTERED, WorkloadState.STALE):
        try:
            await transition(session, workload, WorkloadState.ATTESTING, caller.principal)
        except InvalidTransitionError as e:
            raise HTTPException(status_code=409, detail=str(e))
    elif workload.current_state != WorkloadState.ATTESTING:
        raise HTTPException(
            status_code=409,
            detail=f"cannot attest workload in state {workload.current_state.value}",
        )

    # Run backend verification
    from server.main import get_backend_registry
    registry = get_backend_registry()
    backend = registry.get(workload.backend_type.value)
    att_result = await backend.verify(workload)

    # Record result
    record = AttestationRecord(
        workload_id=workload.id,
        backend=workload.backend_type,
        verdict=att_result.verdict,
        evidence_hash=att_result.evidence_hash,
        detail=att_result.detail,
    )
    session.add(record)

    # Transition based on result
    from server.models.db import AttestationVerdict
    if att_result.verdict == AttestationVerdict.PASS:
        await transition(session, workload, WorkloadState.HEALTHY, "attestation_result")
        workload.last_attested_at = datetime.now(timezone.utc)
    elif att_result.verdict == AttestationVerdict.FAIL:
        await transition(session, workload, WorkloadState.FAILED, "attestation_result")
    # UNAVAILABLE and ERROR: stay in Attesting, don't transition

    await session.commit()
    return {
        "workload_id": str(workload_id),
        "verdict": att_result.verdict.value,
        "state": workload.current_state.value,
        "attestation_id": str(record.id),
    }
```

```python
# server/kbs/store.py
from cryptography.fernet import Fernet
import base64
import hashlib


def _derive_fernet_key(raw_key: bytes) -> bytes:
    digest = hashlib.sha256(raw_key).digest()
    return base64.urlsafe_b64encode(digest)


def encrypt_secret(plaintext: str, key: bytes) -> bytes:
    f = Fernet(_derive_fernet_key(key))
    return f.encrypt(plaintext.encode())


def decrypt_secret(ciphertext: bytes, key: bytes) -> str:
    f = Fernet(_derive_fernet_key(key))
    return f.decrypt(ciphertext).decode()
```

```python
# server/kbs/gate.py
from dataclasses import dataclass
from server.models.db import WorkloadState
from server.policy.engine import PolicyEngine, PolicyDecision


@dataclass
class GateResult:
    allowed: bool
    reason: str


async def check_kbs_gate(
    workload_state: WorkloadState,
    attestation_age_seconds: float,
    policy_engine: PolicyEngine | None,
    subject: str,
    resource: str,
    max_attestation_age: int = 3600,
) -> GateResult:
    if workload_state != WorkloadState.HEALTHY:
        return GateResult(allowed=False, reason=f"workload state is {workload_state.value}, must be healthy")

    if attestation_age_seconds > max_attestation_age:
        return GateResult(allowed=False, reason=f"attestation age {attestation_age_seconds}s exceeds max {max_attestation_age}s")

    if policy_engine:
        decision = await policy_engine.evaluate(
            subject=subject,
            action="kbs_release",
            resource=resource,
            context={
                "workload_state": workload_state.value,
                "attestation_age": attestation_age_seconds,
            },
        )
        if not decision.allowed:
            return GateResult(allowed=False, reason=decision.reason)

    return GateResult(allowed=True, reason="all checks passed")
```

```python
            policy_engine=None,
            subject=caller.principal,
            resource=f"{repo}/{secret_type}/{tag}",
        )
        if not gate.allowed:
            raise HTTPException(status_code=403, detail=gate.reason)

    key = _load_encryption_key()
    plaintext = decrypt_secret(secret.encrypted_value, key)

    audit = AuditLog(
        actor=caller.principal, actor_type=caller.actor_type,
        action="kbs_release_secret", target_type="kbs_secret",
        target_id=secret.id,
        detail={"repo": repo, "type": secret_type, "tag": tag},
    )
    session.add(audit)
    await session.commit()

    return {"value": plaintext}
```

```python
def create_mcp_server(api_url: str = "http://localhost:8400") -> FastMCP:
    mcp = FastMCP("arbiter-hub-mcp")
    client = ArbiterClient(base_url=api_url)

    @mcp.tool()
    async def check_workload_status(workload_id: str) -> dict:
        """Check attestation status and state of a workload."""
        return await client.get_workload(workload_id)

    @mcp.tool()
    async def list_workloads_by_state(state: str | None = None) -> dict:
        """List workloads, optionally filtered by state (registered, attesting, healthy, stale, failed, under_remediation, revoked)."""
        return await client.list_workloads(state=state)

    @mcp.tool()
    async def check_compliance(workload_id: str) -> dict:
        """Check if a workload is compliant with active policies."""
        return await client.check_compliance(workload_id)

    @mcp.tool()
    async def verify_artifact(artifact_ref: str) -> dict:
        """Verify a cosign signature on a container image or artifact."""
        return await client.verify_artifact(artifact_ref)

    @mcp.tool()
    async def gate_check(workload_id: str) -> dict:
        """Full gate evaluation: compliance + state + attestation currency."""
        workload = await client.get_workload(workload_id)
        compliance = await client.check_compliance(workload_id)
        return {
            "workload_id": workload_id,
            "gate_passed": (
                workload.get("current_state") == "healthy"
                and compliance.get("compliant", False)
            ),
            "state": workload.get("current_state"),
            "compliance": compliance,
        }

    @mcp.tool()
    async def query_audit_log(actor: str | None = None, action: str | None = None) -> dict:
        """Query the attestation audit log."""
        return await client.query_audit(actor=actor, action=action)

    @mcp.tool()
    async def backend_health() -> dict:
        """Check health status of all attestation backends."""
        return await client.backend_health()

    return mcp
```

```python
# server/plugins/loader.py
from importlib.metadata import entry_points
from typing import Any


class PluginRegistry:
    def __init__(self):
        self.backends: dict[str, Any] = {}
        self.policy_engines: dict[str, Any] = {}
        self.event_handlers: dict[str, Any] = {}

    def register_backend(self, name: str, backend: Any) -> None:
        self.backends[name] = backend

    def register_policy_engine(self, name: str, engine: Any) -> None:
        self.policy_engines[name] = engine

    def register_event_handler(self, name: str, handler: Any) -> None:
        self.event_handlers[name] = handler


def load_entry_point_plugins(group: str) -> dict[str, Any]:
    discovered = {}
    eps = entry_points()
    group_eps = eps.select(group=group) if hasattr(eps, "select") else eps.get(group, [])
    for ep in group_eps:
        try:
            discovered[ep.name] = ep.load()
        except Exception:
            pass
    return discovered
```

```python
# server/telemetry/webhooks.py
import asyncio
import logging
from dataclasses import dataclass, field
import httpx
import yaml
from pathlib import Path

log = logging.getLogger(__name__)


@dataclass
class WebhookConfig:
    name: str
    url: str
    events: list[str]
    format: str = "ocsf"
    auth: str | None = None
    secret: str | None = None
    retry: int = 3


class WebhookDelivery:
    def __init__(self, configs: list[WebhookConfig]):
        self._configs = configs

    @classmethod
    def from_yaml(cls, path: str) -> "WebhookDelivery":
        p = Path(path)
        if not p.exists():
            return cls([])
        with open(p) as f:
            data = yaml.safe_load(f)
        configs = []
        for wh in data.get("webhooks", []):
            configs.append(WebhookConfig(**wh))
        return cls(configs)

    async def deliver(self, event_type: str, payload: dict) -> None:
        matching = [c for c in self._configs if event_type in c.events]
        if not matching:
            return
        tasks = [self._send(cfg, payload) for cfg in matching]
        await asyncio.gather(*tasks, return_exceptions=True)

    async def _send(self, config: WebhookConfig, payload: dict) -> None:
        headers: dict[str, str] = {"Content-Type": "application/json"}
        if config.auth == "bearer_token" and config.secret:
            headers["Authorization"] = f"Bearer {config.secret}"

        for attempt in range(config.retry):
            try:
                async with httpx.AsyncClient(timeout=10) as client:
                    resp = await client.post(config.url, json=payload, headers=headers)
                    resp.raise_for_status()
                    return
            except Exception as e:
                log.warning(
                    "Webhook %s delivery attempt %d failed: %s",
                    config.name, attempt + 1, e,
                )
                if attempt < config.retry - 1:
                    await asyncio.sleep(2 ** attempt)
        log.error("Webhook %s delivery failed after %d attempts", config.name, config.retry)
```

```python
"""
Clevis pin for Arbiter Hub attestation-gated key release.

Usage:
  clevis luks bind -d /dev/sda2 arbiter '{"url":"https://arbiter-hub:8400","workload":"vm-prod-01"}'

Reads JSON config from stdin:
  - url: Arbiter Hub API base URL (required)
  - workload: workload identifier (required)
  - repo: KBS secret repo (default: "luks")
  - type: KBS secret type (default: "key")
  - tag: KBS secret tag (default: "default")
  - cert: client certificate path for mTLS (optional)
  - key: client key path for mTLS (optional)
  - ca: CA certificate path (optional)
"""
import json
import sys
import urllib.request
import urllib.error
import ssl


def main():
    try:
        config = json.load(sys.stdin)
    except json.JSONDecodeError as e:
        print(f"Error: invalid JSON config: {e}", file=sys.stderr)
        sys.exit(1)

    url = config.get("url")
    if not url:
        print("Error: 'url' is required in config", file=sys.stderr)
        sys.exit(1)

    workload = config.get("workload")
    if not workload:
        print("Error: 'workload' is required in config", file=sys.stderr)
        sys.exit(1)

    repo = config.get("repo", "luks")
    secret_type = config.get("type", "key")
    tag = config.get("tag", "default")

    kbs_url = f"{url.rstrip('/')}/kbs/v0/resource/{repo}/{secret_type}/{tag}"

    ctx = ssl.create_default_context()
    if config.get("ca"):
        ctx.load_verify_locations(config["ca"])
    if config.get("cert") and config.get("key"):
        ctx.load_cert_chain(config["cert"], config["key"])

    headers = {
        "X-Caller-Principal": workload,
        "X-Caller-Type": "agent",
        "X-Caller-Roles": "attestation-agent",
        "X-Caller-Scopes": workload.split("@")[0] if "@" in workload else workload,
    }

    req = urllib.request.Request(kbs_url, headers=headers)
    try:
        with urllib.request.urlopen(req, context=ctx, timeout=30) as resp:
            data = json.loads(resp.read())
            key_material = data.get("value", "")
            if not key_material:
                print("Error: empty key material from KBS", file=sys.stderr)
                sys.exit(1)
            sys.stdout.write(key_material)
            sys.stdout.flush()
    except urllib.error.HTTPError as e:
        body = e.read().decode() if e.fp else ""
        print(f"Error: KBS returned {e.code}: {body}", file=sys.stderr)
        sys.exit(1)
    except urllib.error.URLError as e:
        print(f"Error: cannot reach arbiter-hub: {e.reason}", file=sys.stderr)
        sys.exit(1)


if __name__ == "__main__":
    main()
```

```bash
#!/bin/bash
# scripts/setup-ipa-roles.sh
# Sets up IPA roles, groups, and HBAC rules for Arbiter Hub
# Usage: ./setup-ipa-roles.sh EXAMPLE.COM
set -euo pipefail

REALM="${1:?Usage: setup-ipa-roles.sh REALM}"

echo "Setting up Arbiter Hub IPA roles for realm $REALM"

# Groups
for group in attestation-admin attestation-operator attestation-pipeline attestation-viewer attestation-agent; do
    ipa group-add "$group" --desc="Arbiter Hub: $group" 2>/dev/null || echo "Group $group exists"
done

# Roles
ipa role-add "Attestation Admin" --desc="Full arbiter-hub access" 2>/dev/null || true
ipa role-add "Attestation Operator" --desc="Enroll, attest, remediate" 2>/dev/null || true
ipa role-add "Attestation Pipeline" --desc="Attest, sign, verify" 2>/dev/null || true
ipa role-add "Attestation Viewer" --desc="Read-only access" 2>/dev/null || true
ipa role-add "Attestation Agent" --desc="Read + request re-attestation" 2>/dev/null || true

# Associate groups with roles
ipa role-add-member "Attestation Admin" --groups=attestation-admin 2>/dev/null || true
ipa role-add-member "Attestation Operator" --groups=attestation-operator 2>/dev/null || true
ipa role-add-member "Attestation Pipeline" --groups=attestation-pipeline 2>/dev/null || true
ipa role-add-member "Attestation Viewer" --groups=attestation-viewer 2>/dev/null || true
ipa role-add-member "Attestation Agent" --groups=attestation-agent 2>/dev/null || true

# HBAC services
for svc in arbiter-api arbiter-kbs arbiter-mcp arbiter-attest arbiter-sign arbiter-enroll; do
    ipa hbacsvc-add "$svc" --desc="Arbiter Hub: $svc" 2>/dev/null || echo "HBAC service $svc exists"
done

echo "Arbiter Hub IPA setup complete"
touch /etc/arbiter/.ipa-roles-configured
```
